# Knowledge Schema

Every durable Wiki note should use this frontmatter:

```yaml
---
title: ""
type: concept
domain: NPI
status: active
classification: internal
created: YYYY-MM-DD
updated: YYYY-MM-DD
evidence: B
confidence: medium
tags: []
sources: []
related: []
owner: ""
review_date: YYYY-MM-DD
---
```

## Types

- concept
- entity
- process
- problem
- solution
- project
- decision
- synthesis
- meeting
- research
- SOP
- metric

## Status

- draft
- active
- deprecated
- archived
- needs-review
